Metadata

Find the pages whose title or meta description needs work, send them to the market, then turn their new texts into import files.

Find the pages with no H1 or with more than one, and send them to the market to write a new one.

4xx & 5xx errors

Turn Screaming Frog's list of broken links into one row per link to fix: header and footer links once, page links without duplicates, likely false positives set apart.

In Screaming Frog: Bulk Export › Response Codes › Internal & External › All Error (4xx 5xx & No Response) Inlinks. The Client Error (4xx) and Server Error (5xx) exports work too.

How to read the report
Reading file…

Settings

Lists that every tool uses. Changes are saved in this browser only: other people, other browsers and this one after clearing its data get the default lists.

Locales

The locale checkboxes of Page type and Metadata, in this order. New locales go at the end.

    Catalogs

    Suggested in Metadata › Generate XML: products go to a master catalog, categories to a navigation catalog. A catalog typed there is added here when you download.

      Bookmarklets

      Small tools that run on the page you're viewing. To install one, show your bookmarks bar (Ctrl+Shift+B, or ⌘+Shift+B on a Mac) and drag its button there, or create a new bookmark and paste the copied code as its URL. Then click the bookmark on any page of the site.

      Screaming Frog profiles

      The latest Screaming Frog profiles with the custom extraction are in the DEC SharePoint folder. You need them to extract elements such as the Page Designer ID or the GEO page type, which the tools here rely on.

      Open the profiles folder

      Opens in SharePoint (sign in with your L'Oréal account). To use a profile in Screaming Frog: File › Configuration › Load, then choose the downloaded file.
